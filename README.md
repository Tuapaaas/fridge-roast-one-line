One original roast line for a smart fridge, written by a program for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty ($5 in USDC). The line roasts the fridge's pushy door-open notifications against the one thing it never warns you about: the food quietly rotting inside it.

## Run it

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to choose another directory).
